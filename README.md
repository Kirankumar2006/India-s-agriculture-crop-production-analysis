# India Agricultural Cultivation Analysis (1997–2021)

## Project Description

This project presents a comprehensive analysis of India's agricultural cultivation using **Tableau**. The dashboard explores historical agricultural data from **1997 to 2021**, providing meaningful insights into crop production, seasonal patterns, regional performance, and long-term production trends. Through interactive visualizations, dashboards, and stories, users can easily identify agricultural patterns, compare state-wise and seasonal performance, and make data-driven decisions.

The project is designed to support different stakeholders in the agricultural sector:

* **Farmers** can identify high-performing crops, understand seasonal trends, and make informed crop selection decisions to improve productivity and income.
* **Government policymakers** can analyze regional disparities, monitor agricultural growth, identify low-yield areas, and develop effective policies for resource allocation and sustainable farming.
* **Agribusiness investors** can discover profitable crops, evaluate production trends, identify emerging agricultural opportunities, and make informed investment decisions with reduced risk.

## Key Features

* Analysis of agricultural data from **1997–2021**
* Interactive Tableau dashboards and story
* State-wise and region-wise crop production analysis
* Seasonal crop trend visualization
* Long-term agricultural production trends
* Crop productivity and yield comparison
* Data-driven insights for farmers, policymakers, and investors

## Tools Used

* **Tableau** – Data visualization and dashboard development
* **Agricultural Dataset (1997–2021)** – Historical crop production data
* **Microsoft Excel/CSV** – Data preparation and preprocessing

## Objective

The primary objective of this project is to transform agricultural data into interactive visualizations that help users understand cultivation trends, identify growth opportunities, improve decision-making, and promote sustainable agricultural development across India.
